                          Help

                          Getting started

                          Cosmifold is a visual place to organize the things in your life.

                          Create an Item, then add other Items inside it to build your Universe.

                          A few things to know

                          + Add something
                          Add an Item, Task List or content where you are working.
                          … Manage something
                          Rename, move, duplicate or delete the Item you are working with.
                          Tap or click an Item
                          Select it to move through your Universe.
                          Contents
                          Keep Files, Notes, Links and Location inside an Item.
                          Task Lists
                          Choose Add task list for a checklist. Find your lists under Tasks later.

                          Need more help?

                          Navigating

                          Tap or click an Item to select it. Zoom to move through levels, or use the sidebar to navigate directly. Search helps when you forget where something lives; Fit returns to an overview.

                          On desktop, right-click for management actions. On mobile, use ….

                          Adding & organizing Items

                          Items can contain other Items, creating branches. For example, put Japan inside Travel and Tokyo inside Japan. Select an Item and use + to add something inside it.

                          Contents

                          Each Item can hold Files, Notes, Links and Location. On mobile, Preview is the quick view. Swipe up to open Contents, then swipe down to return.

                          Task Lists & Tasks

                          A Task List is a special Item. Only the Items directly inside it are tasks. Tasks can hold Files, Notes, Links and Location, but cannot contain child Items.

                          Check Done to complete a task. Completing tasks brings them to life and updates the Task List's progress. Uncheck Done to undo it.

                          Under Tasks, Active shows lists with unfinished work; Completed shows finished lists.

                          Hide from Tasks removes a completed list from this view only. It remains in the Universe. If it becomes unfinished, it returns to Active automatically.

                          Search

                          Use Search when you know what you want but do not remember where you put it.

                          Constellations

                          Constellations are optional. Use one when Items from different parts of your Universe are useful to see together.

                          If everything naturally belongs in one branch, you probably do not need a Constellation. Original Items are not moved or copied.

                          Moving & duplicating

                          Move changes where an Item lives. Copy / Paste creates an independent copy.

                          Duplicate structure creates reusable organization, leaving content behind. Duplicated Task List tasks start incomplete.

                          Backup & Restore

                          This test build is browser-local: your data lives in this browser. Keep a recent backup of important data.

                          Backup creates a portable copy of Cosmifold data. Restore loads a previous backup, replacing the current local data.

                          Mobile tips

                          Use … for management actions. Swipe Preview up to open Contents; swipe Contents down to return. On a task, you can check Done in Compact Preview.
